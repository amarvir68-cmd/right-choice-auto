# V9 update

Focused professional admin refresh.

## Vehicle photo workflow
- Photo thumbnails now appear immediately on Add Vehicle before saving.
- New photos can be reordered before upload.
- New photos can be removed before upload.
- First new photo becomes the cover when the vehicle has no saved photos.
- Existing saved photos retain Set Cover, reorder, and permanent Delete controls.
- Newly selected photos append after already-saved photos.

## Admin design
- Vehicle form split into professional cards: Vehicle Details, Photos, Listing Status.
- Stronger spacing, hierarchy, upload panel, status explanations and sticky Save bar.
- Dashboard/sidebar styling refined for a dealership CMS feel.

No database migration is required for v9 beyond the v8 analytics migration if that has not already been run.
